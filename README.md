# Chat Stickers

OBS-оверлей, который показывает сообщения публичного Twitch-чата в виде стикеров.

## Запуск

```bash
npm install
npm run dev
```

Введите имя канала, настройте время показа и скопируйте полученную ссылку в OBS: **Источники → Браузер**. Рекомендуемый размер источника — 1920 × 1080. Фон в overlay-режиме прозрачный.

Подключение идёт анонимно к Twitch IRC через локальный sync-server:
авторизация и чат-бот не нужны. Сервер разбирает сообщения, назначает эффекты и
координаты, после чего отправляет единое состояние главной странице и OBS.

## Сборка

```bash
npm run build
```

## Синхронизация с OBS

Запустите локальный WebSocket-сервис перед открытием главной страницы и OBS:

```bash
npm run sync
```

Оставьте процесс работающим во время трансляции. Главная страница и OBS-оверлей
автоматически подключаются к адресу `ws://127.0.0.1:17891`. Без sync-server
приложение не подключается к Twitch и не создаёт стикеры.

## Профили оверлея

Каждая ссылка OBS содержит уникальный `profileId`, название и начальные
настройки профиля. При подключении источника sync-server автоматически создаёт
профиль в памяти, после чего он появляется в списке на главной странице.

Профили имеют независимые настройки, Safe Area, очередь и набор стикеров. Это
позволяет одновременно использовать, например, отдельный источник для наград и
отдельный источник для обычного чата. Настройки сохраняются в локальном
хранилище оверлея и восстанавливаются после перезапуска sync-server при следующем
подключении источника OBS.

## Смайлики

Стикеры поддерживают официальные Twitch emotes (включая авторские смайлики
канала) и глобальные/канальные смайлики 7TV. Распознавание происходит на сервере,
поэтому все клиенты профиля получают одинаковые фрагменты сообщения.

Наборы 7TV загружаются автоматически по `room-id` из Twitch-чата и обновляются
каждые 5 минут. Первые сообщения могут поступить до завершения загрузки набора:
в таком случае неизвестные коды остаются текстом. Изображения загружаются из CDN,
для них требуется доступ к интернету. При ошибке изображения выводится его код.

BTTV, FFZ, персональные и zero-width смайлики пока не поддерживаются.
Проверка реализации: `npm test` (сквозной тест поднимает локальные WebSocket-серверы).
