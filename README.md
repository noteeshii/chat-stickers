# Chat Stickers

OBS-оверлей, который показывает сообщения публичного Twitch-чата в виде стикеров.

## Запуск

```bash
npm install
npm run dev
```

Введите имя канала, настройте время показа и скопируйте полученную ссылку в OBS: **Источники → Браузер**. Рекомендуемый размер источника — 1920 × 1080. Фон в overlay-режиме прозрачный.

Подключение идёт анонимно к Twitch IRC через локальный sync-server:
авторизация и чат-бот не нужны. Сервер разбирает сообщения, назначает эффекты и
координаты, после чего отправляет единое состояние главной странице и OBS.

## Сборка

```bash
npm run build
```

## Синхронизация с OBS

Запустите локальный WebSocket-сервис перед открытием главной страницы и OBS:

```bash
npm run sync
```

Оставьте процесс работающим во время трансляции. Главная страница и OBS-оверлей
автоматически подключаются к адресу `ws://127.0.0.1:17891`. Без sync-server
приложение не подключается к Twitch и не создаёт стикеры.
